# Listar últimas compras en reportes de métricas generales

## Actor and outcome

Un analista consulta el reporte general y espera ver las últimas compras.

## Acceptance criteria

- [ ] Unificar el origen de datos de compras y redenciones.
- [ ] Las compras aparecen en el reporte general.
- [ ] Las redenciones no se duplican.
- [ ] El listado respeta el rango de fechas seleccionado.
